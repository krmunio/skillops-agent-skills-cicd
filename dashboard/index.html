스킬 품질

평가 기준·출처 설명

Anthropic의 스킬 작성 가이드를 참고해 사용 조건·지침의 명확성, 간결성, 문서·리소스 구성과 단계적 정보 제공 구조를 살펴봅니다.

정적 검사와 LLM rubric 결과를 구분합니다. 적용되지 않는 항목은 분모에서 제외하고 이유를 표시합니다. 참고 가이드와 실제 수행된 검사는 동일하지 않으며, 공식 인증을 의미하지 않습니다.

개선 근거

판단 기준 설명

APO의 근거 기반 개선 접근을 참고해 관측된 문제, 개선 가설, 지침 변경과 재평가 결과가 연결되는지 살펴봅니다.

변경 이유만으로 개선을 인정하지 않습니다. 문제와 관련된 변경인지, 같은 조건의 재평가가 주장을 뒷받침하는지 구분합니다. 미기록 근거를 추정하거나 별도 인증 점수를 만들지 않습니다.

Skill이 미연결된 기록도 포함합니다. 실행을 선택하면 위의 평가 결과와 원문이 해당 기록으로 함께 전환됩니다.

저장된 결과를 기다리고 있습니다.

실제 기록은 공개가 허용된 요약과 검토된 Skill 원문을 제공합니다. 미기록 정보는 추정하지 않습니다. 샘플의 지침·평가·변경 내용은 합성 예시이며 실제 이력과 분리됩니다.
