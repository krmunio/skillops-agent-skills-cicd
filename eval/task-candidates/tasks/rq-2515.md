# 일회성 iterable을 받는 일괄 작업 등록

`Queue.enqueue_many()`는 `Iterable[EnqueueData]`를 입력으로 받는다.
의존 작업과 독립 작업을 섞은 generator를 넘기면 일부 작업이 반환 결과에서 사라진다.

일회성 iterable도 list 입력과 같은 의미로 처리하도록 수정하라.
독립 작업은 큐에 등록되어야 하고, 미완료 부모에 의존하는 작업은 저장된
DEFERRED 상태 및 deferred registry에 남아야 한다.
기존 반환 순서, 큐 순서, 내부 pipeline 및 호출자 제공 pipeline의 실행 시점은 보존하라.
관련 회귀 검사를 추가하라.
