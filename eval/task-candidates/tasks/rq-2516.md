# 실패 저장과 후속 작업의 예외 경계

Worker의 일반 실패 처리와 재시도 횟수 소진 처리를 수정하라.
실패 상태 저장, 실패 알림, 의존 작업 등록, 실행 슬롯 반환이 서로의
실패를 잘못 숨기거나 필요한 처리를 건너뛰지 않아야 한다.

실패 상태가 저장되지 않았다면 후속 알림·의존 작업 등록·슬롯 반환을 실행하지 않아야 한다.
저장에 성공한 뒤 의존 작업 등록이 실패하더라도 실행 슬롯 반환은 시도해야 한다.
슬롯 반환 오류 역시 기록되어야 하며 이미 수행한 실패 저장과 후속 처리를 무효화하지 않아야 한다.
정상 경로와 두 종류의 종료 실패 경로를 보존하고, 오류 주입 회귀 검사를 추가하라.
