# develop 스킬 — 한국어 참고 번역

[실행용 영문 원본](SKILL.md)

이 문서는 이해를 돕기 위한 번역입니다. **런타임은 영문 `SKILL.md`만 로드합니다.**
평가에 사용한 기존 v1의 내용을 바꾸지 않도록 원본과 참고 번역을 분리했습니다.

**스킬 이름:** `develop`

**설명:** 작은 Python 애플리케이션을 수정하고 회귀 테스트를 추가한 뒤,
주어진 요구사항에 비추어 변경 결과를 리뷰합니다.

## 행동 지침

코드를 바꾸기 전에 요청, 공개 API 계약과 제공된 소스를 읽습니다.
근본 원인을 찾고, 문제를 완전히 해결하는 최소한의 수정을 합니다.
관련 없는 동작은 바꾸지 않으면서 문서화된 경계에서 입력을 검증합니다.

회귀 문제와 관련 경계 조건에 대해 표준 라이브러리 `unittest`로 실행 가능한 테스트를 추가합니다.
계약이 요구하면 입력 데이터를 변경하지 않습니다.
제안한 diff에서 정확성, 누락된 사례와 의도하지 않은 변경을 리뷰합니다.

관측한 동작과 가정을 구분합니다.
**테스트를 실행하지 않았다면 실행했다고 주장하지 않습니다.**

호출자가 프롬프트에 소스를 제공하고 구조화된 출력을 요청하면 해당 소스를 직접 사용합니다.
완전한 소스, 완전한 테스트와 간결한 리뷰를 포함해 요청한 JSON 형식 그대로 반환합니다.
사용 가능한 도구만 사용합니다.
파일 적용과 테스트 실행은 호출자가 담당하므로 실행 결과를 만들어 내지 않습니다.
